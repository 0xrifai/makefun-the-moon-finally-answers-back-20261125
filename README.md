## Why this line

The field is crowded with four-billion-years-of-wishes, howling, rock-with-no-HR,
good-night, tides, and no-day-off setups, so this entry takes the one angle none
of the 140 live entries use: the Moon as the silent witness. The setup names the
three things the bounty asks the Moon to answer — promises, howls, 3 a.m. texts —
and the turn is that the Moon knows everything embarrassing and is simply too
polite to repeat it. Old, tired, wry, and the comeback lands in the last clause.
